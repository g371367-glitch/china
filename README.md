| Ежемесячно до 15-го | 🇨🇳 | НДФЛ сотрудников (даже нулевой), соцстрах, декларация по освобождению экспорта от НДС | Бухгалтер |

| **До 30 апреля** | 🇷🇺 | Уведомление о КИК (КНД 1120416) + отчётность на русском; 3-НДФЛ, если были дивиденды | Вы / консультант |
