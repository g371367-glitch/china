# Китайские ERP и сервисы аналитики для Ozon

*Актуально на 28.09.2026. Цены взяты с сайтов разработчиков и из китайских обзоров, перед оплатой проверьте их в личном кабинете сервиса.*

---

## 1. Главное: ERP — это не MPStats

Это два **разных типа** сервисов. Большинство продавцов пользуются обоими.

| | **Аналитика** (как MPStats) | **ERP** (как «МойСклад» + SelSup, только для кросс-бордера) |
|---|---|---|
| Для чего | **Смотреть рынок**: что продаётся, по какой цене, сколько зарабатывают конкуренты, какие ниши растут | **Управлять своим магазином**: загрузить товары, обработать заказы, закупить, отправить, посчитать прибыль |
| С чьими данными работает | С данными **всей площадки** (чужие магазины) | С данными **вашего** магазина через API Ozon |
| Главный вопрос | «**Что** продавать?» | «**Как** быстро продавать и не ошибаться?» |
| Российский аналог | MPStats, Moneyplace, SellerFox | МойСклад, SelSup, «Маркетплейс Мастер» |
| Китайские сервисы для Ozon | **萌啦 Menglar** (Ozon + Wildberries) | **妙手 Miaoshou, 店小秘 Dianxiaomi, 芒果店长 Mango, BigSeller** |

**Общее с MPStats:** это облачные сервисы (SaaS). Вы заходите в личный кабинет на сайте и платите подписку. У ERP почти всегда есть **бесплатный тариф**, а деньги берут за количество магазинов и продвинутые функции.

## 2. Что умеет ERP: путь товара от 1688 до покупателя

| Этап | Без ERP (вручную) | С ERP |
|---|---|---|
| 1. Поиск товара | Ищете на 1688 и копируете вручную | **Расширение для браузера**: одна кнопка на странице 1688, Taobao, Pinduoduo или даже на чужой карточке Ozon, и товар попадает в ERP |
| 2. Карточка | Перевод, фото, характеристики, категория — вручную | Автоматический **перевод на русский** (в том числе текста на картинках), подбор категории и атрибутов Ozon, AI-заголовки |
| 3. Цена | Считаете в Excel | **Калькулятор цены**: закупка + логистика + комиссия + курс + желаемая маржа → цена на Ozon |
| 4. Публикация | По одной карточке | **Массовая загрузка** сотен товаров, в несколько магазинов сразу |
| 5. Заказы | Смотреть в кабинете Ozon | Все заказы из всех магазинов в одном окне |
| 6. Закупка (дропшиппинг) | Идти на 1688 и оформлять заказ вручную | **Автозаказ на 1688** по заказу с Ozon, трек отслеживается |
| 7. Отправка | Печатать этикетки по одной | **Массовая печать этикеток**, передача трек-номеров в Ozon (важно для лимита 72 часа) |
| 8. Остатки | Следить вручную | Синхронизация остатков, защита от продажи товара, которого нет |
| 9. Финансы | Сверять отчёты Ozon | Прибыль по заказу и товару с учётом всех расходов |
| 10. Сотрудники | Один логин на всех | Доступы для сотрудников и агента-упаковщика |

## 5. Как подключить ERP (на примере Miaoshou)

| # | Шаг | Где |
|---|---|---|
| 1 | Зарегистрироваться на сайте ERP по китайскому номеру телефона (иногда подходит email) | erp.91miaoshou.com |
| 2 | В кабинете Ozon получить **Client ID** и **API-ключ** | Кабинет Ozon → Настройки → API-ключи |
| 3 | Вставить ключ в ERP: «Авторизация магазина» (店铺授权) → Ozon | Кабинет ERP |
| 4 | Установить **расширение для браузера** (采集插件) | Chrome |
| 5 | Настроить шаблон цены: курс, логистика, маржа | Кабинет ERP |
| 6 | Собрать 5–10 тестовых товаров с 1688, проверить перевод и опубликовать | 1688 → ERP → Ozon |
| 7 | Добавить доступ для агента или упаковщика в Иу (если работаете по дропшиппингу) | Кабинет ERP → сотрудники |

> **Безопасность.** Ключ API даёт сервису доступ к вашему магазину. Подключайте только **официальных партнёров Ozon** (список есть в кабинете Ozon, раздел партнёров). Если перестали пользоваться сервисом, удалите ключ.
