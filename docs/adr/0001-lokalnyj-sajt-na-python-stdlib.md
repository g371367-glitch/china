# 0001. Локальный сайт на Python стандартной библиотеки, без сборки

## Контекст

Заметки — россыпь .md без поиска и навигации. Нужен ещё калькулятор, который сохраняет товары и правки тарифов. Python 3 у владельца уже установлен, владелец не разработчик.

## Решение

База знаний и калькулятор — локальный сайт: «Запустить.bat» поднимает сервер на `http.server` (только 127.0.0.1) и открывает браузер. Интерфейс — статические HTML/CSS/JS, библиотеки лежат в проекте, сборки и npm нет. Заметки читаются с диска при каждом запросе и остаются источником истины.

## Почему

- **Просто открывать .md в редакторе или Obsidian** — нет калькулятора, общего календаря сроков и страницы тарифов, а поиск зависит от чужой программы.
- **Статический HTML без сервера (открыть файлом)** — браузер из `file://` не может писать в `data/`, не может запросить курс у ЦБ (CORS) и не увидит новую заметку без пересборки списка.
- **Node/npm или фреймворк со сборкой** — зависимости нужно ставить и обновлять; сломанная сборка у нетехнического владельца означает нерабочий сайт.
- **Хостинг или доступ с телефона** — данные о компании оказались бы в сети; пользователь выбрал локальный сайт.

## Последствия

- Без открытого окна консоли сайта нет: закрыл окно — сайт остановился.
- На машине нужен Python 3; без него .bat только сообщает, что установить.
- С телефона и другого компьютера сайт недоступен. Чтобы это изменить, придётся заново решать вопрос авторизации.
- Сервер ограничен стандартной библиотекой Python. Серьёзная серверная логика потребует пересмотреть принцип «без зависимостей».
- Индекса нет, поиск — проход по тексту. Если база вырастет на порядки, индекс придётся заводить.
