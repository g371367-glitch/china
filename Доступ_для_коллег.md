# Доступ для коллег

Как открыть эту базу знаний и калькулятор коллегам через интернет — по общему паролю, бесплатно и без регистрации.

## Коротко

- Сайт остаётся на вашем компьютере. В интернет его выводит бесплатный туннель Cloudflare — без аккаунта и без оплаты.
- Коллеги открывают ссылку вида `https://…trycloudflare.com` и вводят общий пароль.
- Данные общие: товар, тариф или настройка, сохранённые коллегой, видны вам и остальным, когда экран открывают заново.
- Доступ работает, **только пока ваш компьютер включён и окно «Доступ для коллег» открыто**.
- **Ссылка меняется при каждом запуске** — после каждого включения отправляйте коллегам новую.

## Как включить

1. Дважды щёлкните **«Доступ для коллег.bat»** в папке базы знаний.
2. **Первый запуск:** окно попросит придумать общий пароль — не короче 8 символов, ввести дважды. Набираемые символы не видны — так и должно быть. Пароль запоминается, в следующий раз его спрашивать не будут.
3. **Если нет программы cloudflared** (это программа-туннель от Cloudflare), окно спросит «Скачать? [Д/Н]». Ответьте «Д» и нажмите Enter — она скачается в папку `tools` (около 60 МБ, один раз).
4. Через несколько секунд (до 40) в окне появится **ссылка для коллег**. Она уже скопирована в буфер обмена — просто вставьте её в сообщение (Ctrl+V).
5. Окно не закрывайте, пока коллеги работают.

## Что отправить коллегам

- Ссылку из окна: `https://<случайные-слова>.trycloudflare.com`.
- Пароль — лучше отдельным сообщением или голосом.
- Коллега открывает ссылку, видит страницу входа, вводит пароль — и попадает на тот же сайт. Вход запоминается на 30 дней (пока не сменится пароль). Выйти — пункт «Выйти» в меню.

Ссылка вида `http://127.0.0.1:…` коллегам **не подходит** — она открывается только на вашем компьютере.

## Как выключить

Закройте окно «Доступ для коллег» (или нажмите в нём Ctrl+C). Туннель остановится, ссылка перестанет открываться.

## У вас всё как раньше

- «Запустить.bat» и `http://127.0.0.1:8765` открываются у вас **без пароля** — и когда доступ для коллег включён, и когда нет.
- Пока доступ включён, на главной вашего сайта видна текущая ссылка для коллег с кнопкой «Копировать».
- Если ваш сайт уже был открыт через «Запустить.bat» до включения доступа, ссылки на главной не будет — берите её из окна «Доступ для коллег» (окно об этом скажет).

## Как сменить пароль

1. Дважды щёлкните **«Сменить пароль.bat»**.
2. Введите новый пароль дважды (не короче 8 символов).
3. Все, кто входил по старому паролю, сразу выходят и должны ввести новый — даже если доступ сейчас включён. Сообщите коллегам новый пароль.

## Коллегам в Китае

Сайты Cloudflare из Китая без VPN обычно не открываются. **Коллегам в Китае нужен включённый VPN.**

## Если не открывается

| Что видно | Что сделать |
|---|---|
| «Туннель не запустился — проверьте интернет…» | Проверьте интернет (если вы сами в Китае — включите VPN) и запустите «Доступ для коллег.bat» ещё раз. |
| «Туннель остановился — доступ для коллег закрыт» | Пропал интернет или туннель оборвался. Запустите «Доступ для коллег.bat» заново и отправьте коллегам **новую** ссылку. |
| Коллега пишет, что ссылка не открывается | Проверьте, что окно «Доступ для коллег» открыто, а компьютер не спит. Убедитесь, что у коллеги свежая ссылка (после перезапуска старая не работает) и у коллеги в Китае включён VPN. |
| «Неверный пароль» | Проверьте раскладку и Caps Lock. Пароль забыли — задайте новый через «Сменить пароль.bat». |
| «Слишком много попыток, попробуйте через N мин» | После нескольких неверных паролей вход временно закрыт — это защита от подбора. Подождите указанное время. |
| «Не удалось скачать cloudflared» | Скачайте вручную файл `cloudflared-windows-amd64.exe` со страницы https://github.com/cloudflare/cloudflared/releases/latest, переименуйте в `cloudflared.exe` и положите в папку `tools` внутри папки базы знаний. Затем снова запустите «Доступ для коллег.bat». |
| «Не найден Python 3» | Установите Python с python.org, при установке отметьте «Add to PATH». |

## Безопасность

- Без пароля по ссылке не открывается ничего: ни заметки, ни калькулятор, ни данные.
- Пароль хранится на вашем компьютере не открытым текстом, а в виде, из которого его не восстановить (файл `data/access.json`); в окне он не печатается.
- Ссылку и пароль давайте только тем, кому доверяете: вошедший коллега может менять товары, тарифы и настройки.

## Открытая копия на GitHub Pages

Второй способ — без вашего компьютера: копия сайта на GitHub Pages, работает круглосуточно, ссылка постоянная (`https://<ваш-логин>.github.io/<репозиторий>/`).

- **Открыто всем**: пароля нет, любой, у кого есть ссылка (или кто найдёт репозиторий), прочитает все заметки.
- Заметки, календарь и исходные тарифы — как у вас. Товары, свои тарифы и настройки у каждого коллеги свои и хранятся **только в его браузере**: общих данных нет, вашего списка товаров коллеги не увидят.
- Копия обновляется сама после каждой отправки изменений на GitHub (`git push`), через 1–2 минуты.

Как включить (один раз):

1. На github.com → **New repository**, тип **Public**, без README.
2. В папке базы знаний: `git remote add origin https://github.com/<логин>/<репозиторий>.git`, затем `git push -u origin master`.
3. В репозитории: **Settings → Pages → Source: GitHub Actions**. Затем **Actions → «Сайт на GitHub Pages» → Run workflow** (или просто следующий `git push`).
4. Ссылка появится в **Settings → Pages** и в итогах запуска в **Actions**.

Ваши личные файлы (`data/settings.json`, `products.json`, `tariffs.json`, `access.json`) на GitHub не попадают — они в `.gitignore`.
