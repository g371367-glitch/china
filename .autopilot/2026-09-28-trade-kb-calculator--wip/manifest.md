- Q6 → R10i: курс CNY/RUB — поле с кнопкой «обновить по ЦБ» (публичное зеркало ЦБ, без ключей), офлайн — последний сохранённый курс, ручная правка; поле «запас на конвертацию, %». Пользователь: «ЦБ онлайн + ручная правка».
- Q7 → R11i, R03: «Запустить.bat» поднимает локальный Python-сервер (127.0.0.1) и открывает сайт; список товаров и правки тарифов пишутся файлами в data/; сайт сам подхватывает новые .md. Пользователь: «Запустить.bat + папка data/».
- Q8 → R02, R03: категории — дом + смежные дешёвые лёгкие (дом и сад, кухня, хранение, хобби, канцелярия, аксессуары, игрушки и т. п., ~10–15), остальные — кнопкой «добавить категорию». Пользователь: «Дом + смежные лёгкие».
- Q9 → R01, R09i: главная — «ближайшие сроки» из сводного календаря КНР+РФ с подсветкой ≤30 дней, ниже разделы и кнопка калькулятора; дата регистрации компании — заглушка, пользователь впишет сам. Пользователь: «Сроки + разделы».

- Q11 → R02: правки прямо в .md-файлах; каждая заменённая цифра — с датой и источником; страница «Что изменилось»; старая версия — в git; факты, которые знает только бухгалтер, не выдумываются — остаётся «уточнить» с готовым вопросом. Пользователь: «Править в файлах + журнал».
