## Что должно заработать

Двойной клик по «Запустить.bat» в корне проекта поднимает локальный сервер на Python (только 127.0.0.1) и открывает браузер на сайте. Слева меню базы знаний по папкам, названия берутся из заголовка `# …` каждой заметки. Заметка открывается отформатированной (таблицы, списки, ссылки); ссылки между заметками открываются внутри сайта. Новая .md в любой папке знаний видна после F5. Поиск по всем заметкам с фрагментами и подсветкой. Сервер уже отдаёт все эндпоинты из спецификации, включая `/api/data/<name>` и `/api/rate`. Экраны калькулятора, тарифов, списка и главной делают таски 03 и 05. Здесь в роутере для них стоят заглушки маршрутов («Раздел в разработке»), а главная пока показывает список разделов.

## Критерии приёмки

- [ ] `Запустить.bat`: находит `python` (затем `py -3`); если нет — «Не найден Python 3. Установите с python.org и отметьте „Add to PATH“» + `pause`. Окно консоли пишет адрес и как остановить. Кириллица в путях и выводе не ломается (`chcp 65001`, `PYTHONUTF8=1`)
- [ ] Порт 8765; если он занят нашим сервером (`/api/ping` → `{"app":"trade-kb"}`), второй запуск только открывает браузер и завершается; если чужим — берётся следующий свободный
- [ ] `GET /api/docs`: все .md из папок знаний и корня; исключены `.autopilot`, `.git`, `app`, `data`, `.claude`, `node_modules`, `CLAUDE.md`, `AGENTS.md`; title из первого `# `, иначе имя файла без `_`
- [ ] `GET /api/doc?path=` отдаёт текст; `..`, абсолютные пути, не-.md, служебные папки → 404; путь с кириллицей работает
- [ ] `GET /api/search?q=` без учёта регистра, ё=е, до 3 фрагментов на заметку, пустой/короче 2 символов → `[]`
- [ ] `GET/PUT /api/data/<name>` по белым спискам из спецификации; отсутствующий файл → `null`; запись атомарная; не-JSON тело → 400; не из белого списка → 404
- [ ] `GET /api/rate` → курс CNY из cbr-xml-daily (Value/Nominal) + дата; при ошибке сети — 502 `{error}` за ≤5 с
- [ ] Ссылки между заметками (относительные, с кириллицей и `%20`) открываются маршрутом `#/doc/…`; якоря внутри страницы работают; внешние — в новой вкладке
- [ ] marked положен в `app/web/vendor/` (без CDN); сайт работает без интернета
- [ ] Светлая/тёмная тема по системе; на ширине 375px меню сворачивается, горизонтальной прокрутки страницы нет (широкие таблицы прокручиваются внутри себя)
- [ ] Тесты `python -m unittest discover app/tests` зелёные: docs, doc с `..` → 404, search, data GET/PUT/белый список, ping
