## Что должно заработать

Сервер, созданный с `access`, пускает только после ввода общего пароля: коллега видит страницу входа
по-русски, вводит пароль и попадает на сайт; вход помнится 30 дней; в меню есть «Выйти». Без входа не
отдаётся ничего, кроме страницы входа и её стилей. Подбор пароля упирается в блокировку. Смена пароля
(`Access.set_password`) сразу выбрасывает всех вошедших, даже если смена сделана другим процессом.
Обычный локальный сервер (без `access`) работает как раньше, без пароля; на его главной, когда задан
`team_info.url`, виден блок «Доступ для коллег включён: <ссылка> [Копировать]».

## Из брифа, дословно

> «вход по паролю»
> «Один общий пароль» — «Проще всего, но нельзя отключить одного человека, не меняя пароль всем.»

## Критерии приёмки

- [ ] `Access`: PBKDF2-SHA256 200 000 итераций, соль 16 байт, `data/access.json` (не читается и не пишется через `/api/data`); `set_password` меняет `secret` → прежние токены `verify` = False; короче `MIN_PASSWORD` → `ValueError` с русским текстом
- [ ] Токен `<выдан>.<HMAC>` base64url, срок 30 дней; cookie `kb_session` HttpOnly, SameSite=Lax, Path=/, Max-Age; Secure при https (`X-Forwarded-Proto` / `Cf-Visitor`)
- [ ] Без входа: не-API GET → 303 `/login`; `/api/*` → 401 `{"error":"Нужно войти"}`; открыты только `GET /login`, `GET /css/style.css`, `POST /api/login`, `POST /api/logout`
- [ ] `LoginLimiter`: 5 неудач с адреса (`Cf-Connecting-IP`, иначе адрес соединения) → 15 мин; 30 неудач за 15 мин со всех → блок всех 15 мин; ответ 429 «Слишком много попыток, попробуйте через N мин»; успех сбрасывает адрес
- [ ] `login.html`: поле пароля, «Войти», «Неверный пароль» с очисткой поля и фокусом; после входа → `/`; без внешних ресурсов
- [ ] `api.js`: любой 401 → переход на `/login`; `api.logout()`, `api.team()`; `/api/ping` → `{app, version, team}`; пункт меню «Выйти» только при `team:true`
- [ ] `/api/team` на локальном → `{active, url?}`, на сервере для коллег → 404; блок со ссылкой и «Копировать» на локальной главной
- [ ] Локальный сервер (без `access`) — все прежние ответы без изменений, прежние тесты зелёные
- [ ] Тесты через `make_server` на временном корне: 303/401, вход верный/неверный, cookie, выход, блокировка (подставные часы), смена пароля из «другого» объекта `Access` гасит вход, `/api/team`
- [ ] Сквозная проверка: `app/team.py` из таска 03 с этим сервером поднимает сайт для коллег без туннеля и вход работает; найденные несостыковки в `team.py` исправить здесь
