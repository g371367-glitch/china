## Что должно заработать

Владелец дважды щёлкает «Доступ для коллег.bat»: при первом запуске придумывает пароль (скрытый ввод,
дважды, ≥ 8 символов); если cloudflared нет — получает вопрос «Скачать? [Д/Н]» и скачивание с прогрессом;
затем поднимаются локальный сайт (8765, без пароля) и сайт для коллег (следующий свободный порт с 8766,
с паролем), запускается быстрый туннель Cloudflare, в окне печатается ссылка `https://…trycloudflare.com`,
она же — в буфере обмена, с подсказкой «ссылка меняется при каждом запуске». Закрыл окно / Ctrl+C —
туннель и серверы остановлены. «Сменить пароль.bat» меняет пароль. Заметка «Доступ для коллег» объясняет
всё простыми словами.

## Из брифа, дословно

> «могу ли я этому сайту дать общий доступ своим коллегам?»
> «Ваш компьютер + туннель» — «Бесплатно: сайт остаётся у вас, а в интернет его выводит туннель (например, Cloudflare Tunnel). Работает, только пока компьютер включён.»
> «Да, с VPN» — «Берём бесплатный туннель Cloudflare: без аккаунта и без денег, но ссылка меняется при каждом запуске, и новую нужно снова отправить коллегам.»

## Критерии приёмки

- [ ] `parse_tunnel_url(line)` вытаскивает `https://<x>.trycloudflare.com` из строк вывода cloudflared (в т.ч. из рамки `|  https://…  |`), прочее → None; тесты на образцах строк
- [ ] `find_cloudflared(root)`: `tools/cloudflared.exe`, затем PATH; `download_cloudflared` — во временный файл, затем переименование; ошибка сети → русский текст со ссылкой для ручной загрузки
- [ ] `Tunnel.start(timeout=40)` возвращает ссылку или бросает ошибку с русским текстом; `alive()`, `stop()` гасит процесс; при падении туннеля во время работы в окне — «Туннель остановился — доступ для коллег закрыт»
- [ ] Первый запуск без `data/access.json` — ввод пароля (`getpass`), дважды, ≥ 8, повтор при ошибке; `--set-password` — только смена и выход
- [ ] Если 8765 уже занят нашим сервером — поднимается только сайт для коллег, в окне сказано, что ссылки на главной не будет; иначе локальный сервер получает `team_info` со ссылкой
- [ ] Ссылка в буфере обмена (`clip` на Windows; без него — молча пропустить); в окне — ссылка, «ссылка меняется при каждом запуске», «закройте окно, чтобы закрыть доступ»
- [ ] Закрытие окна / Ctrl+C гасит cloudflared (`atexit` + `SetConsoleCtrlHandler` через ctypes, где доступно)
- [ ] Bat-файлы: CRLF, UTF-8 без BOM, `chcp 65001`, поиск Python как в «Запустить.bat», `pause` при ошибке; сообщения без трассировок Python
- [ ] `Доступ_для_коллег.md`: как включить, какую ссылку отправить, ссылка меняется при каждом запуске, смена пароля, работает пока компьютер включён и окно открыто, коллегам в Китае нужен VPN, что делать, если не открывается
- [ ] `python -m unittest discover -s app/tests -p test_team.py` зелёный; реальный cloudflared в тестах не запускается
